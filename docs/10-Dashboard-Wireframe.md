# Dashboard Wireframe

## Purpose

The Dashboard is the main screen users see after opening EngFore.
Its purpose is to provide a quick overview of learning progress and easy access to continue studying.

---

# Dashboard Sections

## 1. Welcome Hero

Display:

- Greeting
- User name
- Short motivation
- Continue Learning button

---

## 2. Daily Goal

Display today's learning goals.

Example:

- Learn 20 words
- Complete 1 grammar lesson
- Study for 30 minutes

---

## 3. Statistics

Show four summary cards.

- Vocabulary
- Grammar
- Reading
- Listening

Each card contains:

- Icon
- Title
- Value
- Progress

---

## 4. Continue Learning

Show recently studied lessons.

Each card contains:

- Lesson title
- Progress
- Continue button

---

## 5. Recent Activity

Timeline of completed activities.

Example:

- Learned 25 words
- Finished Grammar Quiz
- Completed Reading Exercise

---

## 6. Recommended Lessons

Recommend lessons based on learning progress.

# Responsive Rules

Desktop

- Two-column layout
- Four statistics cards in one row

Tablet

- Two-column layout when possible
- Statistics become 2 × 2 grid

Mobile

- Single-column layout
- Full-width cards
- Comfortable spacing

---

# Design Principles

- Clean interface
- Minimal distractions
- Focus on learning
- Consistent spacing
- Responsive design
- Reusable components
- Use Design System variables only
